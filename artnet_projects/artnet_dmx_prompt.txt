screen 5, device connect screen, muncul ketika device konek ke hotspot esp32, tulisannya begini, line atas, Device Connect!, line bawah, Loading..., , durasi 3 detik, setelah device konek, selanjutnya bakal balik lagi ke screen 4 wifi setup screen atau mode ap
screen 6, module connect1 screen, muncul ketika esp32 connect ke wifi setelah connect dari web hotspot, stelah itu module melakukan reboot, tulisannya line atas, Module Connect!, line bawah Rebooting..., , durasi 3 detik, kalau sudah konek ke wifi, selanjutnya reboot dulu dan masuk ke boot screen
screen 7, module connect2 screen, muncul ketika esp32 connect ke wifi setelah connect screen, kayak autoconnect gitu, alurnya dari reboot, boot screen, connect screen, baru screen ini, lanjut run screen, tulisannya line atas, Module Connect!, line bawah Loading..., , durasi 3 detik kalau sudah konek ke wifi, selanjutnya masuk ke screen 8
screen 8, run screen, mode run standby dan looping, tulisannya begini, line atas, ARTNET-DMX, ada animasi looping 6 step, ARTNET-DMX, ARTNET-DMX >, ARTNET-DMX >>, ARTNET-DMX >>>, ARTNET-DMX >>>>, ARTNET-DMX >>>>>, usahakan agar tidak flicker dan kedip, dibuat smooth aja, line bawah, 192.168.X.X, durasi screen ini akan lama karena looping terus menerus, kecuali ada case di screen 9 dan 10
screen 9, wifi reset, ketika tombol reset di webserver ditekan, akan muncul screen ini dulu di lcd, selanjutnya module akan melakukan reboot, lalu masuk connect screen, wifi not connect screen, wifi setup screen atau mode ap,  tulisannya begini, line atas, WiFi Reset!, line bawah, Rebooting..., durasi 3 detik, setelah itu reboot dan sesuai alur tadi, ujungnya tetap ke screen 4 wifi setup screen, karena akan konfigurasi ulang wifi
screen 10, wifi disconnect1, ketika wifi putus atau mati <30 detik, akan muncul screen ini, tulisannya begini, line atas, WiFi Disconnect!, line bawah, Reconnecting...,  misal putus <30 detik, akan reconnect terus menerus, dan durasi screen ini 30 detik, kalau reconnect berhasil, masuk run screen, kalau reconnect tidak berhasil, masuk ke screen 11
screen 10, wifi disconnect2, ketika wifi putus atau mati >30 detik, akan muncul screen ini, tulisannya begini, line atas, WiFi Disconnect!, line bawah, Rebooting,  misal putus >30 detik, akan muncul screen ini, module akan melakukan reboot, alur sesuai yg diatas, sama seperti wifi reset, ujungnya akan ke mode ap untuk konfigurasi wifi
screen 11, wifi failed, ketika salah memasukkan password wifi, akan muncul screen ini, tulisannya begini, WiFi Failed!, line bawah, Wrong Password..., durasi 3 detiik, setelah itu kembali ke screen 4 wifi setup screen, karena akan konfigurasi ulang wifi
