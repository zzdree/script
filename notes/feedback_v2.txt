==============================================
3. HEADER / TITLE BAR
==============================================

Layout header (kiri ke kanan):
  [Icon + ZZLUXORA] [Nama Project / Path File Project]

- Hapus tulisan "ZZLIGHT LUXORA" dari area header bawah
- Nama project dan path file ditampilkan di header windows, di samping icon + ZZLUXORA

Status bar di header (rata kanan):
  [Art-Net Connected/Disconnected] [Play/Pause]

- Art-Net status: hijau = connected, merah = disconnected
- Play/Pause: cukup 1 tombol toggle, bukan 2 tombol terpisah
- Tombol blackout: icon lingkaran hitam di sebelah kanan play/pause
  → Fungsi: set semua slider mixer ke 0 (channel master + channel 1-512)

Menu bar (rata kiri):
  [File] [View] [Help]

21. INSTALLER & UNINSTALLER
==============================================

Installer:
  - Instalasi ke: Program Files atau Program Files (x86)
  - Data disimpan di: AppData Local atau AppData Roaming
  - Sebelum install: hapus folder app yang lama di Program Files, lalu copy fresh (tidak menimpa)
  - Opsi saat install: keep atau hapus data di AppData (clean install vs upgrade)

Uninstaller:
  - Folder di Program Files: dihapus bersih
  - Opsi: keep pengaturan/data di AppData atau ikut dihapus
  - Folder bersih setelah uninstall (kecuali user pilih keep settings)

Kebutuhan: untuk testing dan publish
