3.1. LEVEL 1: TITLE BAR (JENDELA SISTEM & PATH PROYEK)
--------------------------------------------------------------------------------
- Pojok Kiri Atas: Logo icon `zz` (20x20px) + Teks `ZZLUXORA` warna putih bersih.
- Samping Kanan Nama App: Menampilkan alamat/path proyek lengkap dan nama file `.zlx` aktif
  (Contoh: `D:\projects\worship\Sunday_Live.zlx` atau `[Untitled.zlx]`).
- Pojok Kanan Atas: Tombol kontrol jendela OS (Minimize, Maximize, Close).

--------------------------------------------------------------------------------
3.2. LEVEL 2: MAIN MENU BAR (SISTEM JENDELA POP-UP WINDOWED)
--------------------------------------------------------------------------------
- Posisi: Tepat di bawah Title Bar.
- Items: `File`, `Fixture`, `Editor`, `Preview`, `Setting`, `Help`, `About`.
- Sifat Interaksi:
  * `File`: Dropdown menu biasa (`Open Project (Ctrl+O)`, `Save Project (Ctrl+S)`, `Save As (Ctrl+Shift+S)`, `Exit`).
  * `Fixture`, `Editor`, `Preview`, `Setting`, `Help`, `About`: **SEMUANYA MEMBUKA JENDELA POP-UP INDEPENDEN!**
  * Sifat Jendela Pop-up:
    - Default status: **Windowed** (bukan dialog modal kaku yang memblokir layar utama).
    - Memiliki tombol kontrol window lengkap: *Minimize, Maximize, Close*.
    - Dapat di-maximize penuh, digeser, atau diletakkan di monitor sekunder.

--------------------------------------------------------------------------------
3.3. LEVEL 3: PROGRAM VIEW BAR (SEJAJAR HORIZONTAL)
--------------------------------------------------------------------------------
- Posisi: Tepat di atas area kerja workspace program.
- Sisi Kiri (Tab Switcher):
  * Tombol navigasi 6 workspace: `[Address]`, `[Analyze]`, `[Result]`, `[Perform]`, `[Page]`, `[Mixer]`.
  * Status tab aktif ditandai dengan warna highlight dan garis bawah aksen amber grandMA3.
- Sisi Kanan (Status & Kontrol Utama — Sejajar Langsung dengan Tab):
  1. **Art-Net Status Badge:**
     * Menampilkan status transmisi: `[ART-NET: IDLE]` (Merah) atau `[ART-NET: TRANSMITTING]` (Hijau).
     * Klik pada status badge langsung membuka pop-up dialog `Setting`.
  2. **Tombol Blackout:**
     * Berbentuk lingkaran hitam pekat berbingkai kontras (`○ Blackout`).
     * Menekan tombol ini seketika mereset Grand Master Fader menjadi 0.
  3. **Tombol Play / Stop Toggle (Satu Tombol Tunggal):**
     * State Idle (Berhenti)  : Menampilkan icon Play segitiga hijau (`▶ Play`). Begitu diklik, transmisi Art-Net aktif dan tombol otomatis BERUBAH menjadi tombol Stop.
     * State Active (Berjalan): Menampilkan icon Stop persegi merah (`■ Stop`). Begitu diklik, transmisi berhenti dan tombol BERUBAH kembali menjadi tombol Play.

================================================================================

- Fitur Undo/Redo berlaku untuk **SELURUH PROGRAM SECARA GLOBAL**, bukan hanya di Tab Address:

  * `Ctrl+Z`: Undo aksi terakhir.
  * `Ctrl+Shift+Z` / `Ctrl+Y`: Redo aksi terakhir.

6. SPESIFIKASI ENAM TAB WORKSPACE UTAMA
================================================================================

--------------------------------------------------------------------------------
6.1. TAB 1: ADDRESS (DMX PATCH SHEET)
--------------------------------------------------------------------------------
- Matriks 256 kanal DMX (maksimal 24 kotak horizontal per baris, scroll vertikal).
- Kotak kosong: Pure dark grey `#282c34`, nomor kanal di sudut kanan atas.
- Kotak terisi: Warna latar mengikuti jenis fungsi kanal:
  * Dimmer -> Amber (#d97706)
  * Red -> Merah (#dc2626)
  * Green -> Hijau (#16a34a)
  * Blue -> Biru (#2563eb)
  * White -> Putih (#f8fafc)
  * Strobe -> Kuning (#eab308)
- Label kanal di tengah kotak, nomor kanal tetap di kanan atas.
- Tombol [Clear All Patch] dengan dialog konfirmasi keamanan (tercatat di Undo Stack).

--------------------------------------------------------------------------------
6.2. TAB 2: ANALYZE (AUDIO & DSP CORE ENGINE)
--------------------------------------------------------------------------------
- Input Audio:
  1. Tombol `[📁 Load Audio File]`: Membuka file explorer lokal (.wav, .mp3, .flac, .ogg).
  2. Tombol `[🌐 Import from YouTube]`: **MEMBUKA POP-UP KHUSUS YOUTUBE DOWNLOADER**:
     * Dialog pop-up berisi kolom input URL YouTube.
     * Tombol Download & Extract Audio ke `data/audio/`.
     * Progress bar download mandiri. Setelah tuntas, otomatis ter-load ke Analyze.
- Tombol `[Analyze]` dan `[Remove Song]` (disabled jika lagu belum dimuat).
- Proses Analisis Asinkron Non-blocking:
  * Area analisis diberi efek visual blur/dimmed tanpa mengunci antarmuka.
  * Menampilkan progress bar dan penjelasan ilmiah DSP secara dinamis (STFT Hann, Chroma, MFCC, Russell Plane).

--------------------------------------------------------------------------------
6.3. TAB 3: RESULT (ANALYSIS DASHBOARD & EXPORT)
--------------------------------------------------------------------------------
- Menampilkan hasil ekstraksi audio rohani:
  * Koordinat Russell 2D Plane ($V, A$).
  * Nilai BPM dan estimasi ketukan.
  * Kuadran Mood Ibadah (*Q1 Praise* vs *Q3 Worship*).
  * Palet warna pencahayaan panggung (HSV -> RGBW).
- Tombol `[Re-Analyze]` untuk mengulang kalkulasi.
- Tombol `[Export to Perform]` untuk mengirim data lagu ke Tab Perform.

--------------------------------------------------------------------------------
6.4. TAB 4: PERFORM (STAGE SHOW CONTROLLER & GENERATOR)
--------------------------------------------------------------------------------
- Pengaturan playlist lagu pertunjukan live (bisa ubah urutan / drag reorder, hapus).
- Pemetaan cue pencahayaan (Intro, Verse, Chorus, Bridge, Outro).
- Pengaturan durasi transisi (*fade time*) dan kecepatan *chase*.
- **Tombol `[⚡ Export / Generate to Page]`**:
  * Mengonversi urutan scene dan lagu di Perform menjadi tombol-tombol eksekutor otomatis di Tab Page!

--------------------------------------------------------------------------------
6.5. TAB 5: PAGE (VIRTUAL EXECUTOR SHEET)
--------------------------------------------------------------------------------
- Halaman virtual executor buttons berstandar grandMA3 & Virtual Console QLC+.
- Tombol-tombol eksekutor yang dihasilkan otomatis dari Tab Perform:
  * Tombol trigger instan suasana lagu (Praise, Worship, Verse, Chorus).
  * Tombol Flash (strobe sementara).
  * Tombol Play / Stop kontrol pertunjukan per lagu.

--------------------------------------------------------------------------------
6.6. TAB 6: MIXER (GRANDMA3 257 FADER CONSOLE)
--------------------------------------------------------------------------------
- 257 Fader Fisik Virtual: 1 Grand Master Dimmer (paling kiri) + 256 Kanal DMX (1-256).
- Desain Taktil grandMA3 (Sesuai Gambar Referensi 01 s.d. 05):
  * *Tactile Ribbed Fader Cap*: Cap berkontur dengan cekungan ergonomis dan garis penunjuk putih presisi.
  * *Illuminated Groove Rail*: Jalur rel fader dengan efek LED menyala lembut di belakang cap (Amber untuk Master, Cyan untuk DMX channels).
  * *Calibration Marks*: Garis skala kalibrasi analog di samping rel fader (0%, 50%, 100%).
  * *Smooth Horizontal Scrolling*: Scrollbar horizontal halus untuk menjelajahi fader kanal.
  * Tombol `[Refresh]` di pojok kanan atas.
