     * Tombol lingkaran bertema konsol panggung.

  3. Play / Stop Toggle Button:
     * Desain 1 tombol tunggal yang berganti status (bukan 2 tombol terpisah).
     * State Play: Icon segitiga hijau (▶), mengaktifkan transmisi paket UDP Art-Net secara real-time.

10. ENAM TAB UTAMA PROGRAM VIEW (WORKSPACES)
================================================================================

--------------------------------------------------------------------------------
10.1. TAB 1: ADDRESS (DMX PATCH SHEET)
--------------------------------------------------------------------------------
- Konsep: Matriks DMX Address bergaya QLC+ Fixture Patch Sheet.
- Geometri Grid:
  * Maksimal 24 kotak horizontal per baris.
  * Total 256 kanal DMX (Kanal 1 s.d. 256), dilengkapi scrollbar vertikal halus.
- Aturan Visualisasi Kotak:
  * Kotak Kosong (Unpatched):
    - Warna latar abu-abu gelap industrial (#1a1d24).
    - Nomor kanal ditampilkan di pojok kanan atas kotak.
  * Kotak Terisi (Patched):
    - Warna latar menyesuaikan tipe kanal dari Fixture Profile:
      * Dimmer  -> Aksen Amber emas (#d97706) dengan icon lampu.
      * Red     -> Blok Merah cerah (#dc2626).
      * Green   -> Blok Hijau cerah (#16a34a).
      * Blue    -> Blok Biru cerah (#2563eb).
      * White   -> Blok Putih panggung (#f8fafc).
      * Strobe  -> Blok Kuning kilat (#eab308) dengan icon kilat/petir.
    - Keterangan label kanal berada di posisi TENGAH kotak.
    - Nomor kanal DMX tetap berada di POJOK KANAN ATAS kotak.
- Kontrol Aksi:
  * Tombol [Clear All Patch]: Mengosongkan seluruh patch dengan pop-up konfirmasi.
  * Riwayat Aksi (Undo & Redo):
    - Undo (Ctrl+Z) dan Redo (Ctrl+Shift+Z) memulihkan kondisi patch sebelum di-clear.

--------------------------------------------------------------------------------
10.2. TAB 2: ANALYZE (CORE ENGINE SKRIPSI)
--------------------------------------------------------------------------------
- Konsep: Pusat komputasi ekstraksi audio cerdas berbasis formulasi matematis Bab 2 & Bab 3.
- Komponen Input Audio:
  1. Tombol [Load Audio]: Membuka file explorer native, mendukung .mp3, .wav, .flac, .ogg.
  2. Input YouTube Link:
     * Kolom teks untuk memasukkan URL YouTube.
     * Fitur download & konversi otomatis ke audio lokal di direktori data aplikasi.
  3. Tombol [Analyze]: Memulai komputasi sinyal audio STFT & ekstraksi fitur.
  4. Tombol [Remove Song]: Menghapus lagu terpilih dari sesi analisis.
- State Management Tombol:
  * [Analyze] dan [Remove Song] dinonaktifkan (disabled) jika belum ada lagu yang dimuat.
- Perilaku Saat Analisis Berjalan (Asynchronous Non-Blocking):
  * Area analisis diberi efek blur/dimmed visual.
  * Aplikasi tetap responsif (user bebas berpindah ke tab lain tanpa lagging/freeze).
  * Menampilkan progress bar terkalibrasi disertai teks deskriptif ilmiah yang dinamis:
    - "Menerapkan Hann Windowing (N=2048, H=512) meredam spectral leakage..."
    - "Menghitung FFT Cooley-Tukey Radix-2 & Ekstraksi Spectral Centroid..."
    - "Mengekstrak 12-Semitone Chroma STFT untuk analisis tonalitas harmoni..."
    - "Menghitung 13 Koefisien MFCC & Deteksi Onset Spectral Flux..."
    - "Memetakan koordinat ke Russell 2D Plane (Valence-Arousal)..."
- Output Analisis: Perhitungan mood dan profil panggung per-lagu secara presisi.

--------------------------------------------------------------------------------
10.3. TAB 3: RESULT (ANALYSIS DASHBOARD & EXPORT)
--------------------------------------------------------------------------------
- Konsep: Rekapitulasi hasil komputasi audio dari Tab Analyze.
- Komponen & Fitur:
  * Songlist terpilih dengan urutan yang rapi dan terstruktur.
  * Panel metrik detail per lagu:
    - Estimasi BPM & Ketukan (Beat Grid).
    - Nilai Valence ($V$) dan Arousal ($A$).
    - Kuadran Mood Ibadah (Q1 Praise / Sukacita vs Q3 Worship / Khidmat).
    - Palet warna dominan (HSV -> RGBW).
  * Tombol [Re-Analyze]: Memungkinkan analisis ulang jika parameter audio disesuaikan.
  * Tombol [Export to Perform]: Mengonversi hasil analisis audio menjadi rentetan cue panggung ke Tab Perform.

--------------------------------------------------------------------------------
10.4. TAB 4: PERFORM (STAGE SHOW CONTROLLER)
--------------------------------------------------------------------------------
- Konsep: Pengaturan urutan pertunjukan panggung live ibadah / konser.
- Komponen & Fitur:
  * Playlist urutan lagu ibadah (bisa ubah urutan / drag reorder, hapus lagu).
  * Parameter Scene & Cue Lighting:
    - Pengaturan section lagu (Intro, Verse, Chorus, Bridge, Ending).
    - Waktu transisi (*fade-in / fade-out time*).
    - Kecepatan chase (*chase interval & timing*).
  * Pemetaan Shortcut keyboard untuk eksekusi cue live saat pertunjukan berlangsung.

--------------------------------------------------------------------------------
10.5. TAB 5: PAGE (VIRTUAL EXECUTOR SHEET)
--------------------------------------------------------------------------------
- Konsep: Lembar tombol virtual interaktif (mengadopsi Virtual Console QLC+ dan Executor Page grandMA3).
- Komponen & Fitur:
  * Grid tombol custom untuk eksekusi instan preset suasana (Praise, Worship, Solo, Altar Call).
  * Tombol Flash (strobe sementara saat tombol ditekan).
  * Tombol Play dan Stop untuk kontrol pertunjukan per-bagian.

--------------------------------------------------------------------------------
10.6. TAB 6: MIXER (GRANDMA3 STYLE 513 FADER CONSOLE)
--------------------------------------------------------------------------------
- Konsep: Meja fader virtual profesional berestetika grandMA3 dan konsol studio rekaman.
- Konfigurasi Fader:
  * Fader Paling Kiri : Grand Master Fader (Master Dimmer 0–255).
  * 256 Fader Kanal    : Kanal DMX 1 s.d. 256 (0–255 per fader).
  * Total Fader       : 257 Fader fisik terkalibrasi.
  * Dilengkapi horizontal smooth scrollbar untuk menjelajah fader dengan nyaman.
- Desain & Estetika Fader (Mengacu pada Gambar Referensi Image 01–05):
  * Fader Cap: Desain taktil bersirip (ribbed texture) dengan lekukan cekung jari dan garis indikator putih presisi di tengah.
  * Fader Track (Groove): Dilengkapi jalur LED backlight menyala lembut di belakang track slider (aksen amber/cyan khas grandMA3).
  * Garis Kalibrasi: Skala garis bergradasi di samping track slider menyerupai fader audio/lighting konsol studio kelas atas.
  * Tombol [Refresh]: Terletak di pojok kanan atas untuk menyinkronkan ulang seluruh status fader.

12. SINKRONISASI REKAYASA & SKRIPSI
================================================================================

- Core engine Python di folder `core/` tetap terisolasi murni dari GUI (Decoupled Architecture).
- Seluruh perhitungan pada Tab Analyze mengeksekusi modul `fft_engine.py`, `feature_extractor.py`, `emotion_model.py`, dan `color_engine.py` yang telah lulus 11 unit test.
- Protokol Art-Net UDP Port 6454 mematuhi format biner Art-Net 4 DMX512 (530 byte datagram).
- Repositori GitHub `zzdree/zzluxora-v10` dan `zzdree/script` adalah sumber kebenaran tunggal (*Single Source of Truth*).
