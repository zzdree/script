- Sisi Kanan (Status & Kontrol Utama):
  1. **Art-Net Status Badge:**
     * Menampilkan status transmisi: `[ART-NET: IDLE]` (Merah) atau `[ART-NET: TRANSMITTING]` (Hijau).
     * Klik pada status badge langsung membuka pop-up dialog `Setting`.
  2. **Tombol Blackout:**
     * Berbentuk tombol industrial hitam berbingkai merah (`[BLACKOUT]`).

  3. **Tombol Play / Stop Toggle (Satu Tombol Tunggal):**
     * State Idle (Berhenti)  : Menampilkan `[PLAY]` (Hijau). Transmisi paket Art-Net mati.
     * State Active (Berjalan): Menampilkan `[STOP]` (Merah). Transmisi paket Art-Net aktif dan streaming kontinyu 43.07 FPS.

4. ATURAN TRANSMISI ART-NET & PLAY-GATED SYSTEM
================================================================================

- **Transmisi Strictly Play-Gated:**
  * Paket Art-Net UDP Port 6454 **HANYA AKAN DIKIRIMKAN ketika tombol PLAY aktif** (`is_transmitting == True`).
  * Ketika PLAY belum ditekan: Menggeser fader atau memicu scene di aplikasi berada dalam *Preparation Mode* (hanya memperbarui GUI internal & visualizer tanpa memancarkan paket ke jaringan).
  * Ketika PLAY ditekan: Sistem langsung mengirimkan paket DMX aktual seketika dan streaming berjalan pada laju $43.07\text{ FPS}$ (interval $\approx 23.22\text{ ms}$).

9. SPESIFIKASI ENAM TAB WORKSPACE UTAMA
================================================================================

--------------------------------------------------------------------------------
9.1. TAB 1: ADDRESS (DMX PATCH SHEET)
--------------------------------------------------------------------------------
- Matriks 256 kanal DMX (maksimal 24 kotak horizontal per baris, scroll vertikal).
- Ukuran sel: 46x46px (dioptimalkan untuk layar 768p dan 1080p).
- Kotak kosong: Pure dark grey `#282c34`, nomor kanal di sudut kanan atas.
- Kotak terisi: Warna latar mengikuti jenis fungsi kanal:
  * Dimmer -> Amber (#d97706) [DIM]
  * Red -> Merah (#dc2626) [RED]
  * Green -> Hijau (#16a34a) [GRN]
  * Blue -> Biru (#2563eb) [BLU]
  * White -> Putih (#f8fafc) [WHT]
  * Strobe -> Kuning (#eab308) [STR]
- Label kanal di tengah kotak, nomor kanal tetap di kanan atas.
- Tombol: `[UNDO (Ctrl+Z)]`, `[REDO (Ctrl+Y)]`, `[AUTO PATCH (4 PAR)]`, `[CLEAR PATCH]`.

--------------------------------------------------------------------------------
9.2. TAB 2: ANALYZE (AUDIO & DSP CORE ENGINE)
--------------------------------------------------------------------------------
- Input Audio:
  1. Tombol `[LOAD AUDIO...]`: Membuka file explorer lokal (.wav, .mp3, .flac, .ogg).
  2. Tombol `[IMPORT YOUTUBE...]`: Membuka pop-up khusus YouTube Downloader.
- Tombol `[ANALYZE]` dan `[REMOVE SONG]` (disabled jika lagu belum dimuat).
- Proses Analisis Asinkron Non-blocking:
  * Area analisis diberi efek visual blur/dimmed tanpa mengunci antarmuka.
  * Menampilkan progress bar dan penjelasan ilmiah DSP secara dinamis (STFT Hann, Chroma, MFCC, Russell Plane).

--------------------------------------------------------------------------------
9.3. TAB 3: RESULT (ANALYSIS DASHBOARD & EXPORT)
--------------------------------------------------------------------------------
- Menampilkan hasil ekstraksi audio rohani:
  * Koordinat Russell 2D Plane ($V, A$).
  * Nilai BPM dan estimasi ketukan.
  * Kuadran Mood Ibadah (*Q1 Praise* vs *Q3 Worship*).
  * Palet warna pencahayaan panggung (HSV -> RGBW).
- Tombol `[RE-ANALYZE]` untuk mengulang kalkulasi.
- Tombol `[EXPORT TO PERFORM]` untuk mengirim data lagu ke Tab Perform.

--------------------------------------------------------------------------------
9.4. TAB 4: PERFORM (STAGE SHOW CONTROLLER & GENERATOR)
--------------------------------------------------------------------------------
- Pengaturan playlist lagu pertunjukan live (tombol `[MOVE UP]`, `[MOVE DOWN]`, `[DELETE]`).
- Pemetaan cue pencahayaan (Intro, Verse, Chorus, Bridge, Outro).
- Pengaturan durasi transisi (*fade time*) dan kecepatan *chase*.
- Tombol `[GENERATE EXECUTORS]`:
  * Mengonversi urutan scene dan lagu di Perform menjadi tombol-tombol eksekutor otomatis di Tab Page!

--------------------------------------------------------------------------------
9.5. TAB 5: PAGE (VIRTUAL EXECUTOR SHEET)
--------------------------------------------------------------------------------
- Halaman virtual executor buttons berstandar grandMA2/grandMA3 & Virtual Console QLC+.
- Tombol eksekutor yang dihasilkan otomatis dari Tab Perform:
  * Tombol trigger instan suasana lagu (Praise, Worship, Verse, Chorus).
  * Tombol Flash Strobe.
  * Tombol `[CLEAR PAGE]` untuk membersihkan halaman.

--------------------------------------------------------------------------------
9.6. TAB 6: MIXER (GRANDMA CONSOLE 257 FADERS)
--------------------------------------------------------------------------------
- 257 Fader Fisik Virtual: 1 Grand Master Dimmer (paling kiri) + 256 Kanal DMX (1-256).
- Desain Taktil grandMA:
  * *Tactile Ribbed Fader Cap*: Cap berkontur dengan cekungan ergonomis dan garis penunjuk putih presisi (lebar 30px, tinggi 18px).
  * *Illuminated Groove Rail*: Jalur rel fader dengan efek LED menyala lembut di belakang cap (Amber untuk Master, Cyan untuk DMX channels).
  * *Calibration Marks*: Garis skala kalibrasi analog di samping rel fader (0%, 50%, 100%).
  * *Smooth Horizontal Scrolling*: Scrollbar horizontal halus untuk menjelajahi fader kanal.
  * Tombol: `[RESET DMX]`, `[FULL MASTER]`, `[REFRESH]`.
- Dioptimalkan untuk responsivitas layar 768p dan 1080p.
